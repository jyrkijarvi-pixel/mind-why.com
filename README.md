# MIND - WHY | An interface for common sense

This is a minimalist dashboard tool, optimized for performance and logic. It is built to reduce digital noise and centralize your most essential resources in one place.

## Why this tool?
- **Zero-bloat:** No unnecessary scripts or heavy libraries.
- **ICT-Logic:** Designed for professionals who value speed and direct connections.
- **Customizable:** Easy to fork and modify to suit your own workflow.

## Usage
- **Search:** Type in the search box and press Enter – your query is sent directly to Gemini.
- **Modes:** Switch between Dynamic (Dark) and Classic (Light) modes with a single click.

## Technical Details
- **Frontend:** Pure HTML5, CSS3, and Vanilla JavaScript.
- **Deployment:** Hosted via GitHub Pages.
